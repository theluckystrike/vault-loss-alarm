# Backup review

## Before you accept a new baseline

1. Check the missing paths in the loss report.
2. Open your backup and find the named files.
3. Check whether sync has finished.
4. Restore the files, or accept the deletion if it was planned.

## Sample vault

The QA steps create project notes and text attachments in Demo files.
They delete those sample files to show the free alarm and the restore list.
The backup contains Planning, Draft, Meeting, Budget, Invoice and Map.

## Recent review
